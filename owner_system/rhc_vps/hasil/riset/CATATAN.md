# Riset — BUKAN hasil final

File di folder ini adalah jejak eksperimen, disimpan supaya tidak ada yang hilang. Jangan dipakai sebagai bukti performa.

- `mc_minggu.txt` — Monte Carlo (SINTETIS: trade asli, urutan waktu diacak). Tidak dipakai di hasil final.
- `trade_final.json`, `kurva_asli.json`, `arena_equity.json` — arena 16–17 Sep dengan model keluar v3 yang ternyata dilatih dari periode yang sama (bocor). Diganti uji maju di `../uji_maju_final/`.
- `uji_retrain.log` — uji frekuensi latih ulang (5/10/20/50/100 trade); dihentikan sebelum selesai.
- `auc_exit.json` — AUC model keluar v3.
